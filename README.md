# Landing Page Pilot

Landing page institucional construída com Next.js, TypeScript e Tailwind CSS, com foco em responsividade, navegação fluida e apresentação visual dos serviços.

## Sobre o projeto

A página foi organizada em componentes reutilizáveis e reúne as principais seções de um site institucional:

- apresentação principal;
- sobre a empresa;
- indicadores e resultados;
- serviços;
- portfólio de trabalhos;
- depoimentos;
- perguntas frequentes;
- formulário de contato;
- cabeçalho responsivo com comportamento baseado no scroll.

As transições usam Framer Motion e os conteúdos em carrossel utilizam Swiper. A interface também conta com componentes Radix UI e ícones Lucide.

## Tecnologias

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Radix UI
- Swiper
- React CountUp

## Como executar

```bash
git clone https://github.com/BragaHigor/landing-page-pilot.git
cd landing-page-pilot
npm install
npm run dev
```

Acesse `http://localhost:3000` no navegador.

## Comandos

```bash
npm run dev    # ambiente de desenvolvimento
npm run build  # build de produção
npm start      # inicia o build de produção
npm run lint   # análise do código
```
